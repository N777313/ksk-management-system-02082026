# 1. Общая информация о проекте

## Название системы

**KSK Management System**

Информационная система управления коммунальными квитанциями, жильцами, квартирами и домами для КСК (компания управления многоквартирными домами).

---

# 2. Цель проекта

Создать цифровую платформу для автоматизации работы КСК:

* прием коммунальных квитанций от жителей;
* хранение документов;
* автоматическое распознавание данных через OCR;
* учет домов и квартир;
* управление жильцами;
* контроль оплаты коммунальных услуг;
* административный контроль;
* личный кабинет жильца.

# Техническое задание

## Информационная система управления коммунальными платежами и финансами многоквартирного дома

## 1. Общая информация о проекте

### Название проекта:

**Система учёта коммунальных платежей, доходов и расходов многоквартирного дома**

### Назначение системы:

Разработать приложение для автоматизации управления финансовыми потоками многоквартирного дома:

* учёт квартир;
* автоматическое начисление ежемесячных платежей;
* контроль оплаты жильцами;
* учёт переплат и задолженностей;
* учёт денежных поступлений;
* учёт расходов дома;
* учёт заработной платы сотрудников;
* формирование чеков и финансовых отчётов;
* обеспечение прозрачности для администратора.

---

# 2. Исходные данные дома

Система должна поддерживать следующую структуру:

## Дом:

* количество этажей: 4;
* количество подъездов: 6;
* квартир в каждом подъезде: 8;
* общее количество квартир: 48.

Расчёт:

```
6 подъездов × 8 квартир = 48 квартир
```

---

## Тариф:

Каждая квартира оплачивает:

```
5400 ₸ в месяц
```

Назначение платежа:

* уборка подъезда;
* мойка полов;
* уборка территории возле подъезда;
* вывоз/уборка мусора возле подъезда.

---

Администратор может:

* видеть переплаты;

## 3.2 Сотрудники

Примеры:

Сотрудник может иметь:
